# Sway Configuration

My personal Sway window manager configuration.

## Features

- Custom keybindings
- Dual monitor setup (DP-1 primary, DP-2 secondary)
- Waybar integration
- German keyboard layout

## Files

- `config` - Main Sway configuration file
- `config.d/nightlight.conf` - Nightlight configuration
- `confignano` - Additional configuration

## Installation

Copy the configuration files to `~/.config/sway/`
